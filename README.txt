HAPPY BIRTHDAY, JAANPAKHI - GitHub Pages guide

1. On github.com create a new repository (for example: jaanpakhi). Public is fine.
2. Click "Add file" > "Upload files". Upload index.html and .nojekyll from this zip. Commit.
3. Go to Settings > Pages. Under "Build and deployment" choose:
   Source: Deploy from a branch, Branch: main, Folder: / (root). Save.
4. After about a minute your link is ready:
   https://YOUR-USERNAME.github.io/jaanpakhi/
5. Send that link to her phone.
